# Privacy Policy

**Last updated:** 24 September 2026

This Privacy Policy explains how **videofab** ("the tool"), a private application operated by the owner of the YouTube channel "Por qué será" ("the owner"), accesses, uses and stores data obtained through the YouTube API Services.

## 1. Use of YouTube API Services

videofab uses the YouTube API Services. By using this tool you agree to be bound by the [YouTube Terms of Service](https://www.youtube.com/t/terms). Google's handling of data is governed by the [Google Privacy Policy](https://policies.google.com/privacy).

## 2. Who uses the tool

videofab is used exclusively by the owner to manage their own YouTube channel. It is not offered to the public and has no other users.

## 3. What data is accessed

Through OAuth 2.0, with the owner's explicit consent, the tool requests access to:

- **Upload videos** to the owner's channel and set their metadata and thumbnails (`youtube.upload` scope).
- **Read the list of videos** on the owner's own channel, only to avoid uploading the same video twice (`youtube.readonly` scope).

The tool does not access, collect or process data from any other YouTube user or channel, including comments, subscribers or viewing data.

## 4. How data is used

The data is used only to upload and schedule the owner's own videos and to check their upload status. It is not used for advertising, analytics, profiling or any other purpose.

## 5. How data is stored

- The OAuth access and refresh tokens are stored **only on the owner's personal computer**, in a local file with restricted permissions. They are never sent to any server other than Google's.
- The only YouTube data stored locally is the ID and publish date of each video uploaded by the tool, kept in a local database so the tool knows what has already been published.
- No data is stored on external servers or cloud services operated by the owner.

## 6. Sharing of data

No data obtained through the YouTube API Services is sold, shared with or disclosed to any third party.

## 7. Cookies and tracking

videofab is a local application. It does not use cookies, tracking technologies or analytics.

## 8. Revoking access and deleting data

Access can be revoked at any time from the Google Account security settings: [https://security.google.com/settings/security/permissions](https://security.google.com/settings/security/permissions). Revoking access immediately invalidates the stored tokens. Locally stored tokens and video IDs can be deleted at any time by removing the tool's local data files; they are deleted within 7 days of the tool no longer being used.

## 9. Changes to this policy

Any changes to this policy will be published on this page with an updated date.
